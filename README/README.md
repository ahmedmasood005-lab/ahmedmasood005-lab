## About Me

![Profile](https://img.shields.io/badge/PROFILE-DATA%20%7C%20AI%20%7C%20ENGINEERING-7C3AED?style=for-the-badge&labelColor=0F172A)

I am **Ahmed Masood**, a **BS Data Science student at Pak-Austria Fachhochschule (PAF-IAST)** with hands-on internship experience in data cleaning, exploratory data analysis, visualization, machine learning, and technical documentation. I build end-to-end analytical products that connect reliable data preparation and predictive modeling with practical dashboards and user-friendly interfaces.

My work includes healthcare analytics, missing-data repair, readmission-risk modeling, AI-assisted clinic booking, deepfake detection, business intelligence, classification, and regression. I approach every project with a product mindset: define the real problem, build a reproducible pipeline, evaluate honestly, communicate the result clearly, and make the solution usable.

<details open>
<summary><b>Hospital Readmission Risk Model</b></summary>

<br>

An end-to-end medical risk-classification system designed to estimate 30-day hospital readmission risk while emphasizing recall, calibration, explainability, and clinically meaningful decision thresholds.

| Area | Implementation |
|---|---|
| Stack | Python, Pandas, scikit-learn, XGBoost, Plotly, Streamlit, Tkinter, SQLite |
| Scale | Reproducible 8,000-record synthetic healthcare dataset |
| Performance | Model comparison, ROC-AUC, precision/recall, calibration, and confusion-matrix analysis |
| Security | SQLite authentication, PBKDF2 password hashing, roles, and audit logs |
| Impact | Threshold simulation, cost estimates, patient-level explanations, batch scoring, and reports |
| Repository | [View Project](https://github.com/ahmedmasood005-lab?tab=repositories&q=hospital-readmission) |

The solution combines a responsive dashboard with an offline prediction application. It includes dynamic KPIs, searchable patient records, model performance analysis, explainability views, CSV/PDF exports, trained artifacts, tests, and deployment documentation.

</details>

<details>
<summary><b>Hospital Bed Occupancy Missing-Data Repair</b></summary>

<br>

A healthcare data-quality project that compares multiple strategies for repairing irregular gaps in hospital census and bed-occupancy data.

| Area | Implementation |
|---|---|
| Stack | Python, Pandas, NumPy, SciPy, scikit-learn, Matplotlib, Tkinter |
| Scale | MCAR, MAR, and MNAR missingness scenarios with multiple imputation methods |
| Performance | Method comparison using reconstruction error, distribution shift, and bias analysis |
| Reliability | Reproducible transformations and documented per-column method selection |
| Impact | Helps analysts select an appropriate imputation strategy instead of using one method everywhere |
| Repository | [View Project](https://github.com/ahmedmasood005-lab/Hospital-Bed-Occupancy-Missing-Data-Repair) |

The workflow evaluates mean, median, KNN, interpolation, and other repair strategies, then presents the comparison in a colorful analytical interface with exportable results.

</details>
